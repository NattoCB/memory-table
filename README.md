# 记忆牌桌 · Memory Table

两个纯前端扑克记忆小游戏，为专注练习留一点时间。无需账户、服务器、安装或网络：下载仓库后直接在浏览器打开 `index.html` 即可。界面适配桌面和手机。

## 游戏

- **N-back Poker**：记住牌面，回答 N 张之前的花色和点数。N 可在 1–30 之间设置，默认 2。
- **矩阵翻牌**：翻开两张牌寻找完全相同的配对；不同档位改变牌阵、牌面范围、容错与倒计时。

训练可以从轻松的档位开始。游戏内成绩只反映游戏表现，不能用于诊断或证明日常记忆能力的改善，也不能替代医疗建议。

## 本地运行

直接双击 `index.html`，或在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。无需构建步骤或第三方依赖。所有游戏状态在当前页面内处理，不上传数据。

## 测试

安装 Node.js 后，在仓库目录运行：

```sh
node --test tests/*.test.cjs
```
